# Сборщик вакансий

Инструкция для Claude, который собирает вакансии через Chrome пользователя.
Сборщик ничего не отправляет на сайтах и не откликается: только ищет, читает и сохраняет.

## Перед запуском

1. Прочитать `collector.config.json`.
2. Плановый запуск: если `enabled` равно `false`, ничего не делать и завершиться.
   Ручной запуск по просьбе пользователя идёт всегда.
3. Если площадка просит войти или показывает капчу, остановиться и попросить пользователя пройти её самому.

## Поиск

- Площадки: `sources` (linkedin, indeed).
- Запросы: `queries`, по каждому отдельный поиск.
- Регионы: удалёнка (`targets.remote`) и страны релокации (`targets.relocation_countries`: EU, AE).
- Только вакансии не старше `max_age_days`, не больше `max_vacancies_per_source` с площадки за запуск.
- Темп как у человека: открывать карточки по одной, без массовых параллельных запросов.

## Что сохранять

По каждой вакансии открыть полное описание и заполнить поля из README ("Формат файла сборщика").
Важные поля, которые легко пропустить:

- `external_id`: ID из URL (LinkedIn `/jobs/view/<id>`, Indeed `jk=<id>`).
- `remote_region` и `open_to_kz`: "Remote (EU only)", "must reside in", "work authorization" означают `open_to_kz: "no"`;
  "worldwide", "anywhere", явная поддержка релокации означают `yes`; иначе `unknown`.
- `relocation`, `visa_sponsorship`: `true`, только если это прямо написано; `false`, если прямо исключено; иначе `null`.
- `salary`: только если вилка указана в вакансии. Не угадывать.
- `description`: сжатое, но точное изложение (роль, требования, nice-to-have, условия, вилка). Полный текст доступен по `url`.

## Особенности LinkedIn

- Бейдж "Remote" на карточке ненадёжен: у части вакансий в тексте написано hybrid или onsite. `remote_type` ставить по тексту.
- Для ЕС работает `geoId=91000000` (European Union) + `f_WT=2` (remote). Для ОАЭ использовать `location=United%20Arab%20Emirates`, geoId там подставляет EMEA.
- Вакансии с пометкой Emiratisation только для граждан ОАЭ, их пропускать.

## Оценка соответствия (match_score 0-100)

Сравнивать с мастер-CV пользователя (скилл cv-tailor, `master_cv.json`):

- Основной язык Java или Kotlin, Spring Boot, микросервисы: до 35
- Уровень Senior / Lead / Staff: до 15
- Совпадения стека (PostgreSQL, RabbitMQ/Kafka, Redis, Kubernetes, Docker, CI/CD): до 20
- Домен финтех, банкинг, платежи: до 15
- Доступность для кандидата из Казахстана (удалёнка без ограничения по резидентству или релокация): до 15

В `match_reason` одна-две фразы: что совпало и что мешает.

## Результат

Один файл на площадку за запуск: `data/inbox/<source>_<YYYY-MM-DDTHH-mm>.json`.
Приложение импортирует его само в течение минуты. После записи коротко сообщить пользователю:
сколько найдено, сколько с score 70+, и топ-3 вакансии.
